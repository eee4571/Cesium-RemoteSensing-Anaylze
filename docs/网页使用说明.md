# 遥感影像分析工作台网页使用说明

本文面向网页端使用者，说明如何打开系统、加载遥感数据、从 Google Earth Engine 下载影像，并完成 NDVI、NDWI、NDBI 指数分析和双时相变化检测。

## 1. 启动与访问

### 1.1 启动后端

在项目根目录打开 PowerShell：

```powershell
cd backend
python -m uvicorn app.main:app --reload --port 8000
```

后端正常启动后会显示类似：

```text
Uvicorn running on http://127.0.0.1:8000
```

如果提示端口被占用，说明已有后端进程在运行。可以先确认 `http://127.0.0.1:8000/health` 是否可访问；如果需要重启后端，先停止旧进程再重新运行。

### 1.2 启动前端

另开一个 PowerShell：

```powershell
cd frontend
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```

### 1.3 使用 GEE 前的认证检查

如果需要从 Google Earth Engine 下载影像，先完成认证：

```powershell
earthengine --ee_config "$env:USERPROFILE\.config\earthengine\credentials" authenticate --force
```

认证后验证 Python API 是否能读取凭据：

```powershell
python -c "import ee; ee.Initialize(project='tea123'); print('GEE initialized')"
```

如果输出 `GEE initialized`，再启动或重启后端。注意：后端必须在认证成功后重新启动，才能读取新的凭据。

## 2. 页面分区

网页主体分为三部分：

- 左侧：数据管理、波段显示、影像元数据、对比影像信息。
- 中间：Cesium 地图工作区，用于 2D/3D 浏览、框选范围、查看影像和分析图层。
- 右侧：图层控制、GEE 范围下载、专业分析、坐标点查信息。

地图上方有状态提示条。下载、上传、分析失败时，优先查看这里的提示信息。

## 3. 数据准备

系统支持两种数据来源：

- 本地上传 GeoTIFF。
- 通过地图框选或 Shapefile 范围从 GEE 下载 GeoTIFF。

### 3.1 主影像与对比影像

左侧“数据槽位”有两个选项：

- 主影像：用于单期指数分析，也作为变化检测的前一时相影像。
- 对比影像：用于变化检测的后一时相影像。

上传或下载数据前，先选择要写入的槽位。例如：

- 做 NDVI 分析：只需要选择“主影像”并加载一景影像。
- 做变化检测：先加载“主影像”，再切换到“对比影像”加载第二景影像。

### 3.2 上传本地 GeoTIFF

1. 在左侧选择“主影像”或“对比影像”。
2. 点击或拖拽 TIFF/GeoTIFF 到上传区域。
3. 上传完成后，地图会自动缩放到影像范围。
4. 左侧元数据区会显示文件名、尺寸、波段数、坐标系、分辨率、数据类型和 WGS84 范围。

### 3.3 上传 Shapefile 范围

1. 将 Shapefile 的 `.shp`、`.shx`、`.dbf`、`.prj` 等文件打包为一个 `.zip`。
2. 在左侧上传 zipped Shapefile。
3. 系统会读取矢量范围并转换到 WGS84。
4. 该范围可用于 GEE 下载，也可用于地图缩放和显示。

## 4. 地图浏览与范围选择

### 4.1 2D/3D 切换

地图工具栏提供 `2D` 和 `3D` 按钮。切换时系统会先完成 Cesium 场景切换，再整理相机视角。重复点击当前模式不会重置视角。

### 4.2 地图框选

右侧“GEE 范围下载”面板和地图工具栏都可以进入框选模式。

操作步骤：

1. 点击“地图框选”。
2. 在地图上按住鼠标左键拖出矩形范围。
3. 松开鼠标后，范围会显示为橙色矩形。
4. 状态条显示“已选择下载范围”。

框选时地图拖拽控制会临时关闭，因此鼠标拖动会用于画框，不会同时平移地图。框选结束后地图浏览控制会自动恢复。

### 4.3 清除和缩放范围

右侧图层控制区提供：

- 缩放到影像
- 缩放到矢量
- 缩放到框选

GEE 下载区提供“清除框选”，用于删除当前矩形范围。

## 5. 从 GEE 下载遥感影像

### 5.1 下载参数

右侧“GEE 范围下载”面板包含：

- 数据集：默认 `COPERNICUS/S2_SR_HARMONIZED`。
- 开始日期：默认 `2024-01-01`。
- 结束日期：默认 `2024-12-31`。
- 分辨率 m：默认 `10`。

当前网页下载固定使用真彩色波段：

```text
B4,B3,B2
```

对于 Sentinel-2，这三个波段分别对应红、绿、蓝。

### 5.2 使用框选范围下载

1. 选择数据槽位，例如“主影像”。
2. 点击“地图框选”，在地图上拖出研究区。
3. 设置数据集、日期和分辨率。
4. 点击“从 GEE 下载到当前槽位”。
5. 下载成功后，影像会自动加载到当前槽位，并在地图中显示。

### 5.3 使用 Shapefile 范围下载

1. 上传 zipped Shapefile。
2. 不进行地图框选时，系统会使用 Shapefile 的总范围作为 GEE 下载范围。
3. 选择数据槽位。
4. 点击“从 GEE 下载到当前槽位”。

如果同时存在框选范围和 Shapefile，系统优先使用框选范围。

### 5.4 下载范围和分辨率建议

GEE 下载接口会在请求过大时自动尝试放大 scale，例如 `10 -> 20 -> 40 -> 80`。状态条会提示实际分辨率。

建议：

- 第一次测试使用较小范围。
- Sentinel-2 真彩色建议从 `10 m` 或 `20 m` 开始。
- 如果提示请求过大，缩小框选范围或增大分辨率。

## 6. 波段显示与点查

### 6.1 RGB 波段显示

左侧“显示与点查”中可以设置 R、G、B 对应的波段编号。对于 GEE 下载的 Sentinel-2 真彩色影像，下载结果通常已经是 3 波段，因此默认显示：

```text
R = 1
G = 2
B = 3
```

本地上传多波段影像时，可按实际波段编号修改。

### 6.2 透明度

“主影像透明度”滑块控制主影像叠加透明度，便于和底图或分析结果对比。

### 6.3 查询中心像元

点击“查询影像中心像元”可读取主影像中心点的行列号和前几个波段 DN 值。

### 6.4 地图点查

在地图中单击任意位置，右侧“坐标查询”会显示经纬度、地表高程和像元采样信息。

## 7. 遥感分析总流程

推荐使用以下流程完成一次完整分析：

1. 启动后端和前端。
2. 加载主影像：上传 GeoTIFF，或从 GEE 下载到“主影像”槽位。
3. 如需限制研究区，在地图上框选范围。
4. 在右侧“专业分析”中选择分析类型。
5. 设置指数类型和波段。
6. 运行分析。
7. 在弹出的结果窗口中查看、叠加、缩放和下载结果。

## 8. 指数分析

指数分析用于单景影像，支持：

- NDVI
- NDWI
- NDBI

系统后端统一使用归一化差值公式：

```text
Index = (A - B) / (A + B)
```

其中 A 和 B 由网页中的“A 波段”和“B 波段”决定。

### 8.1 常用波段配置

对于 Sentinel-2 原始多光谱数据，常见配置如下：

| 指数 | A 波段 | B 波段 | 含义 |
| --- | --- | --- | --- |
| NDVI | 近红外 NIR | 红光 Red | 植被 |
| NDWI | 绿光 Green | 近红外 NIR | 水体 |
| NDBI | 短波红外 SWIR | 近红外 NIR | 建成区 |

注意：如果你通过当前网页默认 GEE 下载，只下载了 `B4,B3,B2` 三个真彩色波段，不包含 NIR 或 SWIR。因此严格的 NDVI、NDWI、NDBI 分析需要上传或下载包含相应波段的多波段 GeoTIFF。否则虽然程序可以计算，但结果不具备标准遥感指数含义。

### 8.2 运行 NDVI/NDWI/NDBI 分析

1. 加载主影像。
2. 如果只分析局部区域，先进行地图框选。
3. 在右侧“专业分析”中选择“指数分析”。
4. 选择指数类型：`NDVI`、`NDWI` 或 `NDBI`。
5. 设置 A 波段和 B 波段。
6. 可选：启用阈值提取，填写阈值下限和上限。
7. 点击“运行指数分析”。

分析完成后：

- 地图会叠加指数结果预览图层。
- 结果窗口会自动打开。
- 状态条显示分析完成。

### 8.3 阈值提取

启用阈值后，系统只高亮满足以下条件的像元：

```text
threshold_min <= Index <= threshold_max
```

适合用于：

- NDVI 中提取高植被覆盖区。
- NDWI 中提取疑似水体区域。
- NDBI 中提取建成区高响应区域。

结果统计中会额外包含：

- `thresholdPixels`：满足阈值的像元数。
- `thresholdArea`：满足阈值的面积。
- `totalPixels`：本次分析范围内的总像元数。
- `validPixels`：参与统计的有效像元数。
- `nodataPixels`：无效或无数据像元数。
- `validRatio`：有效像元占总像元的比例。
- `areaUnit`：面积统计单位。

阈值下限必须小于或等于阈值上限。NDVI、NDWI、NDBI 等归一化指数通常位于 `-1` 到 `1` 之间，因此系统会拒绝超出该范围的指数阈值。

面积单位由影像坐标系和分辨率决定；如果影像是米制投影，面积通常为平方米；如果影像是经纬度坐标系，面积单位会标记为平方度，不能直接当作平方米解释。

## 9. 双时相变化检测

变化检测用于比较主影像和对比影像的同一指数变化。

系统流程为：

1. 对主影像计算指定指数。
2. 对对比影像计算同一指数。
3. 将对比影像指数重采样/对齐到主影像网格。
4. 计算差值：

```text
Diff = Index_after - Index_before
```

5. 根据阈值分为增加、减少、稳定三类。

### 9.1 数据准备

1. 在左侧选择“主影像”，加载第一期影像。
2. 切换到“对比影像”，加载第二期影像。
3. 两期影像应覆盖同一研究区。
4. 两期影像应使用相同或可对应的波段配置。

如果两期影像几乎没有有效重叠区域，系统会拒绝输出变化检测结果，并提示重叠比例过低。建议重新检查两期影像的范围、坐标系或地图框选范围。

### 9.2 运行变化检测

1. 在右侧“专业分析”中选择“变化检测”。
2. 选择指数类型。
3. 设置 A 波段和 B 波段。
4. 设置变化阈值。
5. 如只分析局部区域，先框选范围。
6. 点击“运行变化检测”。

### 9.3 变化分类含义

后端分类规则为：

```text
Diff > threshold       -> 增加
Diff < -threshold      -> 减少
abs(Diff) <= threshold -> 稳定
```

预览颜色：

- 绿色：增加区域。
- 红色：减少区域。
- 浅色：稳定区域。
- 透明：无效或无数据区域。

结果统计包括：

- `increasePixels`：增加像元数。
- `decreasePixels`：减少像元数。
- `stablePixels`：稳定像元数。
- `increaseArea`：增加面积。
- `decreaseArea`：减少面积。
- `stableArea`：稳定面积。
- `threshold`：本次使用的变化阈值。
- `overlapPixels`：两期影像都有效的重叠像元数。
- `overlapRatio`：重叠有效像元占总像元的比例。
- `areaUnit`：面积统计单位。

变化阈值必须大于 `0`，且不应超过 `2`。因为两个归一化指数差值的理论范围约为 `-2` 到 `2`。

## 10. 分析结果查看与下载

分析完成后，系统会打开“分析结果”窗口。

每条结果提供：

- 显示开关：控制结果图层是否叠加在地图上。
- 透明度滑块：控制结果图层透明度。
- 缩放到结果：地图定位到该结果范围。
- 下载结果：下载 GeoTIFF。
- 统计：打开 JSON 统计文件。

结果同时会作为图层叠加在 Cesium 地图中。可以结合主影像透明度、底图开关和结果透明度进行对比分析。

## 11. 推荐示例流程

### 11.1 示例一：计算单期 NDVI

1. 准备一景包含红光和近红外波段的 GeoTIFF。
2. 选择“主影像”，上传该 GeoTIFF。
3. 框选研究区。
4. 进入“专业分析 -> 指数分析”。
5. 指数类型选择 `NDVI`。
6. 设置 A 波段为近红外，B 波段为红光。
7. 点击“运行指数分析”。
8. 在结果窗口查看 NDVI 图层、下载 GeoTIFF 和 JSON 统计。

### 11.2 示例二：提取高植被覆盖区

1. 按示例一完成主影像加载。
2. 指数类型选择 `NDVI`。
3. 启用阈值提取。
4. 设置阈值下限为 `0.3`，阈值上限为 `1.0`。
5. 点击“运行指数分析”。
6. 查看 `thresholdPixels`、`thresholdArea`、`validRatio` 和 `areaUnit`。

### 11.3 示例三：双时相植被变化检测

1. 选择“主影像”，加载较早日期影像。
2. 选择“对比影像”，加载较晚日期影像。
3. 框选同一研究区。
4. 进入“专业分析 -> 变化检测”。
5. 指数类型选择 `NDVI`。
6. 设置 A 波段为近红外，B 波段为红光。
7. 设置阈值，例如 `0.2`。
8. 点击“运行变化检测”。
9. 绿色区域表示 NDVI 明显增加，红色区域表示 NDVI 明显减少。

## 12. 常见问题

### 12.1 GEE 提示未认证

先运行：

```powershell
earthengine --ee_config "$env:USERPROFILE\.config\earthengine\credentials" authenticate --force
```

再验证：

```powershell
python -c "import ee; ee.Initialize(project='tea123'); print('GEE initialized')"
```

验证成功后重启后端。

### 12.2 后端 8000 端口无法启动

先检查是否已有后端正在运行：

```powershell
netstat -ano | findstr :8000
```

如果已有监听进程，可直接使用现有后端；如果需要重启，先停止旧进程。

### 12.3 GEE 请求过大

处理方式：

- 缩小地图框选范围。
- 增大 scale，例如从 `10` 改为 `30` 或 `60`。
- 缩短日期范围。

### 12.4 分析按钮不可用

可能原因：

- 指数分析需要先加载主影像。
- 变化检测需要同时加载主影像和对比影像。
- 系统正处于上传、下载或分析中，需等待当前任务完成。

### 12.5 指数结果不符合预期

重点检查：

- A/B 波段是否设置正确。
- 影像是否包含计算该指数所需的波段。
- 是否误用了只包含 `B4,B3,B2` 的真彩色影像计算 NDVI/NDWI/NDBI。
- 是否选择了错误的研究区范围。

## 13. 输出文件说明

每次分析会生成三类文件：

- `result.tif`：分析结果 GeoTIFF，包含指数值或变化差值。
- `preview.png`：用于网页叠加显示的预览图。
- `stats.json`：统计结果，包括总像元、有效像元、无数据像元、有效比例、最大值、最小值、均值、标准差、面积单位，以及阈值或变化检测统计。

这些文件可在“分析结果”窗口中下载或打开。
